--- layout: default title: "Events" description: "Upcoming and past events on Minestead." --- {% comment %} Events page, driven by _data/events.yml. Two tabs (#past in the address opens the second): Upcoming: the next event as a full card (the same panel as the home page), or a "No events planned yet" panel, then every other upcoming event under Coming up, as a tile in its theme. Past: ended events as tiles, newest first, linking to the event's `recap:` if any. Tile art is the event's `thumb:` image, or else its theme's part="thumb" image, or else the site's pickaxe icon. Both tile grids show 6 per page, with Back/Next when there are more. What's upcoming or past is worked out in the browser (the script below), so the page stays right between site builds. Dev site previews: ?draft includes drafts as if announced; ?now=2027-01-10 shows the page as of that date. {% endcomment %} {% assign built_at = site.time | date: '%s' | plus: 0 %} {% assign events = site.data.events %} {% assign upcoming_at_build = false %} {% for event in events %}{% unless event.draft %} {% assign event_end = event.end | default: event.start %} {% assign ends_at = event_end | date: '%s' | plus: 0 %} {% if built_at < ends_at %}{% assign upcoming_at_build = true %}{% endif %} {% endunless %}{% endfor %} {% assign events_by_date = events | sort: 'start' %} {% assign events_newest_first = events_by_date | reverse %}
