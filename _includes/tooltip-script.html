{% comment %} Minecraft-style item tooltips for anything with a data-tooltip attribute. Lines are split by |, and a line can start with a Minecraft color code (§e, §7, §9...). The first line is the item name, with a small gap under it like in game. With a mouse the tooltip follows the cursor; on touch screens, tapping an item shows its tooltip next to it and tapping anywhere else hides it. Turn it on per page with include_tooltip_script: true in the front matter. {% endcomment %}
