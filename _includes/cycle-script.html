{% comment %} Cycles recipes through their variants, like the Minecraft Wiki's recipe boxes. Inside an element with data-cycle, each slot holds one per variant, all but the first marked hidden, in the same order in every slot. Every tick shows the next variant in all slots together, then fires "mc-cycle" so an open tooltip can follow. Variants can share an image and differ only in data-tooltip (the Painting Picker). Without JavaScript the first variant just stays. Turn it on per page with include_cycle_script: true in the front matter. {% endcomment %}
